STM32
Overview

Building a
Smarter Home.

This Smart House project was designed to simulate a modern automated home system using an STM32 microcontroller and a collection of integrated electronic components.

The system combines sensors, displays, lighting controls, and automation logic to create an interactive smart environment capable of responding to real-time conditions and user inputs.

Throughout this project, I applied embedded systems knowledge, circuit integration, troubleshooting, hardware interfacing, and low-level programming concepts while working with STM32 development boards and peripheral modules.
